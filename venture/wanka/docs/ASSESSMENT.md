## 1. 市场（Market）— YC/a16z "为什么是现在"

**打分：9.0 / 10**

| 指标 | 数据（2026 公开研报） |
|---|---|
| 生成式 AI 内容创作市场 | $26.0B (2026) → $80.1B (2030)，**CAGR 32.5%**（Grand View Research） |
| AI 营销工具市场 | $6.2B (2026) → $20.4B (2036)，CAGR 12.6%（Future Market Insights） |
| AI 内容生成（细分） | $7.09B (2026) → $26.73B (2030)，CAGR 39.3%（Research & Markets） |

**为什么是现在（Why now）**：
1. 跨境电商（TikTok Shop / Temu / SHEIN / 独立站）爆发，海量中小卖家需要**多语言**营销素材，但请不起设计+文案+翻译团队。
2. LLM 成本 18 个月内下降 >10×，单条生成成本已低到可做免费额度获客。
3. 现有工具（Jasper/Copy.ai/Canva）要么偏英文单人工具，要么不针对"卖货结果"。**"针对跨境卖货结果 + 多语言 + 网络模板"是尚未被占满的缝隙。**

**扣分项**：赛道拥挤，巨头（Canva/Adobe/OpenAI 原生）随时可下场；靠"结果数据网络"差异化，而非靠模型。

## 3. 商业模式与吸金能力 — Lean Canvas + SaaS 单位经济

**打分：7.5 / 10**

### 四层收入（已在代码中实现）
1. **订阅**：Starter ¥39 / Pro ¥99 / Team ¥299 每月（`/billing/checkout`）
2. **按量**：额度用尽即 402，引导升级（credit-gated `/generate`）
3. **网络分成**：创作者模板被使用→分成（`/creator/earnings`，护城河飞轮）
4. **广告变现**：激励视频看广告得额度（AppLovin MAX，5 额度/次，日上限）

### 单位经济（用 2026 SaaS 基准对标）
| 指标 | 行业健康线（2026） | 万卡设计目标 | 说明 |
|---|---|---|---|
| 毛利率 | 中位 75%（纯 SaaS 82%） | **85%+** | 边际成本近零，mock 阶段更高 |
| LTV:CAC | ≥3:1 健康，bootstrapped 中位 5.0x | 目标 **≥4:1** | 关键靠低 CAC（内容/裂变获客） |
| 月 churn | B2B 中位 ~3.5% | 需 <5% | 靠"结果数据+已存模板"提高留存 |
| CAC 回收 | 12–18 月为好 | 目标 <6 月 | 低价订阅+自传播可压短 |

### 吸金能力评级：**中高**
- **正面**：Day-1 即可收费；边际成本≈0；四层收入叠加；病毒系数有设计（邀请得额度 + 分享）。
- **风险**：一切取决于 **CAC**。单人无投放预算 → 必须靠**内容营销 + 产品自带裂变 + 平台自然流量**把 CAC 压到极低，否则"能赚但赚得慢"。

> **对"三到六个月赚数百万"的诚实校准**：数学上可行但**概率偏低**。举例：月入 ¥100 万需要
> ~1 万个 Pro(¥99) 付费用户，或对应组合。按 2–5% 付费转化倒推需 20–50 万活跃用户。
> 单人在 3–6 个月内从 0 做到数十万活跃，**需要一次爆款级增长事件**（某平台算法助推 / KOL / 病毒模板）。
> 更稳健的预期：**3–6 个月做到月流水 ¥数万–数十万、验证 PMF 与单位经济**；数百万/月是"跑通后放大"的阶段目标，而非默认结果。这不是打击信心，是把资源押在对的杠杆上（获客 > 再加功能）。

## 4. 护城河与长期前景 — a16z 网络效应框架

**打分：6.5 / 10（长期前景指数 7.5）**

万卡设计了**真护城河**，而非"套壳"：
- **网络效应**：模板越用越多 → 新用户开箱即有高质量模板 → 更愿留存/付费。
- **结果数据飞轮**：`report-win` 收集"哪条素材真的卖货"，形成别人拿不到的**私有结果数据集**，反哺推荐与生成质量。这是对抗 OpenAI/Canva 原生功能的**唯一可持续差异化**。

**冷启动风险（最大长期变量）**：网络效应在用户少时是"负资产"。已用 10+ 预置模板缓解，但真正启动需要前几千真实用户产生真实 win 数据。

## 5. 团队 / 执行 — YC 最看重项（诚实）

- 单人、人文背景、无技术团队、无启动资金、中国、线上优先。

- **建议**：把 90% 精力放在**获客与转化实验**，而不是继续堆功能——功能已经足够 MVP+。

## 7. 上架就绪 & 诚实的时间窗提示（务必知悉）

**代码侧 100% 就绪**，但下列平台有**你我都无法绕过的硬性时间/审核窗口**——这是平台规则，不是代码问题：

| 平台 | 硬性约束 | 现实时间 |
|---|---|---|
| **Google Play**（个人号，2023-11-13 后注册） | 上线前必须**封闭测试 ≥12 名测试员 × 连续 14 天** | **≥14 天，不可跳过** |
| **微信小程序**（AI 生成类） | 需**算法备案 + ICP 备案 + 已备案 HTTPS 域名**（workers.dev 不被接受） | 备案通常 **数天–数周** |
| **Apple App Store** | 必须支持**账号删除**(5.1.1v，已实现)、数字商品走 **IAP**(3.1.1) | 审核 **1–3 天**，偶尔更久 |
| **AppLovin MAX** | 需**账号审核通过**才放量 | **数天** |
| **Web / 官网** | `deploy.sh` 一键上 Cloudflare，**当天可上线、永不失效** | **立即** |

> **诚实结论**：Web 端可以**下周甚至今天**上线开始收费与获客；
> iOS/Android/小程序/广告受平台自身时间窗限制，**不可能全部"下周同时"完成**。
> 建议路径：**先 Web 上线跑增长与收入 → 并行提交各平台走它们的时钟**。
> 这样既不违反任何平台规则，也能最快开始产生现金流。
