# CULTURAL_ENGINE.md — 东方文化/命理模块

## 定位 (ADR-001)
命理/八字/紫微是**用户主动选择的文化反思镜头**,不是决定现实结果的权威因果引擎。任何职业/投资/医疗/法律/婚姻建议都不得仅凭命盘得出。

## 现状
| 模块 | 实现 | 置信度 |
|---|---|---|
| 真太阳时校正 | 经度偏移 + 均时差 | high |
| 八字 (年月日时柱) | lunar-javascript,立春年界 | high |
| 大运 | lunar-javascript | high |
| 五行/旺衰/喜用 | 简化比例映射 | **heuristic** |
| 紫微 (命/身宫、局、主星) | 手工实现,仅主星 | **experimental** |

每次排盘输出携带 `chart.meta.confidence` 与 `chart.meta.disclaimer`。

## 已知局限 (诚实)
- 紫微仅安主星,未含四化、小星、流派差异。
- 喜用神为固定比例阈值,非专业断法。
- **尚无**节气前后/午夜/闰月/时区/夏令时/历史时区/0°经度/180°经度的回归测试集。

## 因此
- 不得宣称"专业精确""分钟级完全准确""100% 命中"。
- 紫微/喜用标 `experimental`/`heuristic`,不用于确定性决策。
- 完成回归测试集前,以上标注不得移除。

## 验证 (单样本,非统计)
创始人样例 `2000-02-05 15:05 徐州(117.2E) 男` → 八字庚辰戊寅癸巳己未、命宫癸未、身宫酉、木三局、命主武曲/身主文昌,逐项一致。**这证明计算实现正确,不构成准确率宣称。**
