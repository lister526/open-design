# Mystica 财务模型（可自己改参数的"算盘"）
**配套文件：`financial_model.csv`（可用 Excel / Google Sheets 打开，改绿色输入格即自动重算逻辑）**

> 目的：让你**用自己的真实投放数据**判断"能不能赚、赚多少、什么时候赚"，而不是听我画饼。
> 所有数字都是**假设（Assumption）**，你要用真实测试数据替换它们。

---

## 1. 核心公式（先记住这 5 条）

1. **访客 → 付费转化率 (CVR)** = 付费笔数 ÷ 访客数
   - 行业现实：下载→付费中位数 **1.5%–2.7%**；北美上四分位可达 **5.5%**。落地页优化后取 **2%–4%** 较稳。
2. **获客成本 (CAC)** = 广告花费 ÷ 新付费用户数
3. **首单毛利** = 首单售价 × 毛利率 − 支付手续费（约 3–5%）
4. **客户终身价值 (LTV)** = 首单毛利 + 复购毛利 × 复购次数 + 会员毛利 × 在网月数
5. **是否健康**：**LTV ÷ CAC ≥ 3** 才算可规模化；**首单毛利 − CAC** 决定你烧不烧钱。

## 2. 三种情景（Scenario）

### 情景 A：纯数字（只卖报告，不卖实物）—— 容易亏
- 假设：客单 $15，毛利 95%（=$14.25），支付费 $0.6 → 首单净毛利 ≈ **$13.65**
- CVR 2%，CPC $0.5 → 每付费用户广告成本 CAC = $0.5 ÷ 2% = **$25**
- **结果：首单 $13.65 − CAC $25 = −$11.35 / 单 → 每卖一单亏 $11。纯数字靠冷广告基本亏。**
- 只有当 CVR 提到 ~4% 且 CPC 降到 ~$0.3（低 CAC 市场 + 好素材），CAC 才降到 ~$7.5，首单才转正。

### 情景 B：数字引流 + 实物复购（推荐模型）—— 能赚
- 首单同上（数字，微亏或打平换客户）。
- 30% 数字买家在 60 天内买 1 件实物（$35，毛利 70% = $24.5）：复购毛利贡献 = 0.3 × $24.5 = **$7.35 / 客**
- 10% 成为会员（$9/月，毛利 90%，平均在网 4 个月 = $32.4）：贡献 = 0.1 × $32.4 = **$3.24 / 客**
- **LTV ≈ 13.65 + 7.35 + 3.24 = $24.24**；若 CAC = $10（低 CAC 市场）→ **LTV/CAC = 2.4**（接近健康）
- 把实物复购率提到 40%、CAC 压到 $8 → **LTV/CAC ≈ 3.4（健康，可放大）**

### 情景 C：规模化（自建供应链后）—— 冲大额净利
- 实物毛利从 Dropship 的 ~30% 提到自建的 ~65–70%，复购率 40%+，会员留存拉长。
- 此时每客 LTV 可到 **$30–40**，CAC $10 → **LTV/CAC 3–4**，可大规模投放。

## 3. 目标倒推：月净利 ¥100 万（≈ $140,000）需要什么？

以情景 B 优化后为基准（**每付费客净利贡献 ≈ $25，扣掉 CAC 后净贡献 ≈ $15/客**）：

| 指标 | 数值 |
|---|---|
| 目标月净利 | ≈ $140,000（¥100 万） |
| 每付费客净贡献（扣 CAC 后） | ≈ $15 |
| **需要的月付费客数** | **≈ 9,300 单/月**（保守）→ 优化到 $25 净贡献则 ≈ 5,600 单/月 |
| 对应 CVR 3% 所需月访客 | **≈ 18–31 万访客/月** |
| 对应 CPC $0.3 所需月广告 | **≈ $5.4 万–9.3 万/月** |

> **含义**：¥100 万/月净利是**"中等规模投放 + 复购跑通"**的量级，不是随手可得，
> 但**在低 CAC 市场把 ROAS 跑正后，靠加预算放大是可达的**。3 个月内数百万 RMB 净利，
> 要求你在前 30 天就把"CAC < LTV"验证出来，然后猛加预算——**这是一场执行战，不是运气战。**

## 4. 现金流（Cash Flow）注意
- **数字产品当天回款**：广告花出去，付费当天到账（扣支付方账期 2–7 天）——现金流友好。
- **实物有账期**：Dropship 先收钱后发货（现金流友好，零库存）；自建备货会占用资金（谨慎）。
- **冷启动建议顺序**：数字打平 → Dropship 实物赚毛利（不压资金）→ 现金流为正后再自建供应链。

## 5. 如何使用配套 CSV
`financial_model.csv` 里：
- **输入区（你要改的）**：月访客、CVR、CPC/CAC、各产品价格与毛利率、复购率、会员转化与留存。
- **输出区（自动算的逻辑）**：首单净毛利、LTV、LTV/CAC、月付费单数、月毛利、月广告、月净利。
- 用法：把 CSV 导入 Google Sheets，按注释把"输出列"改成公式（公式已在注释里给出），
  再逐格替换成你的真实测试数据。**先小预算测，用真数据替换假设，再决定加不加预算。**
