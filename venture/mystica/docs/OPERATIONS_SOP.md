# Mystica 运营 SOP + 30 天冷启动作战手册
**给非技术创始人的"照着做"执行清单。每天知道该干什么、看什么数、什么时候加/停预算。**

> 心法：**先用最小成本验证"CAC < LTV"，再猛加预算放大。** 前 30 天不是为了赚大钱，
> 是为了拿到"这门生意能不能赚"的确定性证据。有了证据，加预算就是加利润。

---

## 第一部分：日常运营 SOP（每天/每周固定动作）

### 每日（15–30 分钟）
1. 看营收看板：访问 `你的域名/api/admin/revenue`（真后端版）或本地看板，记录：昨日访客、付费单、营收、按币种。
2. 看广告后台：每个广告组的 **CTR、CPC、落地页 CVR、CAC**。
3. 处理客服/退款/发货（实物）：24 小时内回复，降低拒付。
4. 记录当日"3 个数"：**访客 / 付费单 / 广告花费**，填进你的表格（`financial_model.csv` 的输入区）。

### 每周（1–2 小时）
1. 复盘素材：砍掉 CTR<1% 或 CAC>首单毛利的组；放大跑正的组（预算 +30–50%）。
2. 复盘产品：哪个价位/产品转化最好？实物 attach 率多少？会员转化多少？
3. 邮件营销：给留资未付费的发一封召回；给已付费的发实物/会员推荐。
4. 更新一版素材（照 `AD_CREATIVES.md` 出 2–3 条新变体）。

### 关键指标红线
- **CTR ≥ 1%**（否则钩子不行，换素材）
- **落地 CVR ≥ 2%**（否则落地页/定价不行）
- **CAC < 首单毛利**（否则每单亏钱，先别放大）
- **LTV / CAC ≥ 3**（达到就大胆加预算）

## 第二部分：30 天冷启动作战手册

### 第 1 周：上线 + 装好"眼睛"（测量能力）
- **Day 1**：按 `DEPLOY_PERMANENT.md` 方案 1，开启 GitHub Pages，拿到**永久链接**。全站点一遍确认能跑。
- **Day 2**：注册广告账户（TikTok Ads / Meta Business）。装好像素/事件（PageView、Lead、Purchase）。
  静态版可先用平台像素 + UTM 参数追踪；真后端版接入事件回传。
- **Day 3**：注册 CJdropshipping/DSers，上 1 款主推水晶手链 + 卷轴证书模板（`SUPPLY_CHAIN.md`）。
- **Day 4–5**：照 `AD_CREATIVES.md` 拍/剪 **5 条**素材（角度1爱情、角度3实物各多拍）。竖屏 9:16。
- **Day 6–7**：搭 5 个广告组，每组 1 条素材，**每组 $10–15/天**，主投**墨西哥+巴西+印度**（低 CAC）。

### 第 2 周：找到"能跑的钩子"
- 让广告跑满 3 天再判断（别频繁改）。
- 每天记 CTR/CPC/CVR/CAC。
- **Day 10–11**：砍掉 CTR<1% 的组；对 CTR 高但没转化的，检查落地页/定价（切语言看本地货币是否正确显示）。
- **Day 12–14**：把表现最好的 1–2 条素材，各出 2 个变体（换钩子/换首帧），继续测。

### 第 3 周：验证"实物+复购"这条利润线
- **Day 15–17**：给数字买家发邮件/站内推实物手链（`AD_CREATIVES.md` 脚本#3 也可做再营销广告）。
  记录 **实物 attach 率**（目标 ≥ 30%）。
- **Day 18–19**：上会员 $9/月的入口，记录会员转化率（目标 ≥ 8–10%）。
- **Day 20–21**：算真实 **LTV/CAC**。若 ≥ 3 → 进入放大；若 < 3 → 继续优化素材/落地/定价，别急着加预算。

### 第 4 周：放大 or 修正
- **若 LTV/CAC ≥ 3**：把跑正的组预算翻倍，复制到相邻市场（西→葡、英→印地→英语全球）。
  同时按 `SUPPLY_CHAIN.md` 阶段 2 准备小批量备货提毛利。
- **若仍 < 3**：聚焦"提 CVR + 提实物 attach + 降 CAC"三件事，再测两周。**不要在亏损单元经济下加预算。**
- **Day 30 复盘**：产出"真实单位经济表"（用真数据填 `financial_model.csv`），决定下月预算与目标。

## 第三部分：里程碑与止损

### 里程碑
- ✅ M1（第 1 周）：永久链接上线 + 广告跑起来 + 能测到数据。
- ✅ M2（第 2 周）：找到 ≥1 个 CTR≥1% 的钩子。
- ✅ M3（第 3 周）：验证实物 attach 率 & 会员转化，算出 LTV/CAC。
- ✅ M4（第 4 周）：LTV/CAC≥3 → 放大；产出真实单位经济。

### 止损纪律（保护你紧缺的现金）
- 单条素材连亏 3 天且 CAC>2×首单毛利 → 立即停。
- 单市场测满 $150–200 仍无正向单元经济 → 换市场/换角度，别死磕。
- **每月广告预算上限 = 你能承受的亏损额**，跑正后再用利润加预算，**永远不要借钱猛投未验证的素材**。

---

## 第四部分：客服/履约话术（降退款、提复购）
- 数字产品：即时交付，页面明确"娱乐/自我反思用途"，降低"不灵验"争议。
- 实物：下单即发确认邮件 + 预计到货时间；到货后发"如何使用你的开运手链"邮件（提升满意度与复购）。
- 退款：数字产品 7 天内不满意可退（争议成本 > 退款成本时果断退，保护账户健康）。
