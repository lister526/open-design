## 三、如何上线（零代码，30 分钟内）

### 1) 部署网站（免费）
把整个 `mystica/` 文件夹拖到以下任一平台，即可获得公开网址：
- **Cloudflare Pages**（推荐，免费、全球快）
- **Vercel** / **Netlify**（同样免费，拖拽即部署）

### 2) 接入收款（这一步才开始赚钱）
出海收款推荐 **Lemon Squeezy** 或 **Paddle**（它们自动帮你代扣全球税费、支持信用卡/PayPal，适合个人创业者），或 **Stripe**。
1. 注册后创建两个产品：`Deep Reading $19`、`Membership $9/mo`
2. 复制它们的 Checkout 链接
3. 打开 `app.js`，找到 `LINKS` 那几行，把 `YOUR-STORE...` 换成你的真实链接。保存、重新部署即可。

### 3) 接入真实 AI 深度报告（提高转化与口碑）
付费后应交付一份真正个性化的长报告。做法：把 `engine.js` 生成的命盘数据（四柱、五行、日主）作为 prompt 喂给一个大模型 API，生成 26 段深度解读。这一步我可以帮你加后端，随时说。

## 四、把演示版升级为生产版（重要诚实说明）

当前 `engine.js` 的八字排盘是**简化演示算法**，年柱准确，但月柱/日柱/时柱与传统精确排盘存在偏差（例如未接入真太阳时与节气精确交接）。**正式收费前必须升级为精确星历**（Swiss Ephemeris + 精确节气表）。这是保证口碑、避免退款和差评的底线。我可以帮你替换成精确版。
