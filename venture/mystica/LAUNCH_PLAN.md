## 0. 先说真话：辨析真伪（这是你要求的「辨别真伪」）

**残酷现实（来自 CB Insights / Failory 创业墓地的教训）：**
- 创业失败第一大原因是「**没有市场需求**」(42%)，第二是「**现金烧光**」(29%)。
- 大多数纯工具型 App 死于「**订阅转化率只有 1~5%**」——用户白嫖完就走。
- 「12 年内进福布斯富豪榜 / 中国前 50」是**极小概率事件**，不该作为经营 KPI。把它当北极星方向可以，但**日常必须盯现金流**。

**因此 Mystica 的设计原则：**
1. 用**已被验证的巨大需求**（占星 + 命理，AstroTalk 一年营收数千万美金、印度日活百万）。
2. **不赌订阅**，靠**一次性付费 + 实物电商**这两个「人性上更容易掏钱」的模型。
3. 差异化护城河：**西方占星 × 中国八字融合**——全网几乎没有第二家英文站在做，这是你的「1 of 1」。

**能不能 2 年内做到「上亿净利润」？**
坦率讲：**难，但并非不可能，且路径清晰。** 关键不在软件本身，而在于**实物电商的规模化 + 付费流量的正向 ROI**。下面给你算账。

## 1. 单位经济模型（Unit Economics）——先证明每一单都赚钱

只有当「**获客成本 < 单个用户终身价值**」时，砸广告才是印钞机，否则是碎钞机。

| 指标 | 保守值 | 说明 |
|---|---|---|
| 免费命盘 → 付费深度报告转化率 | 4% | 行业 2~6%，靠价格锚定/紧迫感/退款保证拉高 |
| 深度报告客单价 | $19 | 主力引流品 |
| 报告买家 → 实物护身符转化 | 12% | 已建立信任后加购，$79 客单 |
| 护身符毛利 | 70% ≈ $55 | 代发成本 $15~24 |
| 平均每付费用户毛利 (含加购/复购) | **≈ $28** | (报告$18净 + 0.12×$55) |
| 目标单个访客获客成本 (CAC) | ≤ $0.6 | TikTok/Meta 到站成本 |
| 访客→付费用户成本 | $0.6 / 4% = **$15** | 每个付费用户获客成本 |

**结论：花 $15 获客，赚回 $28 毛利 → ROI ≈ 1.9x。** 只要守住这条线，投得越多赚得越多。
> ⚠️ 这套数字必须**上线后用真实数据校准**。第一个月的唯一任务就是：把这些格子填上真数。

## 2. 六个月路线图（阶段性目标 + 每周动作）

### 🌱 第 1 月：上线 & 验证（目标：跑通闭环，拿到真实转化数据）
- [ ] 按 `DEPLOY.md` 上线，配好 Lemon Squeezy 真实收款 + OpenAI 密钥
- [ ] 装 GA4 + TikTok Pixel + Meta Pixel（否则你等于蒙眼投广告）
- [ ] 用 $500~1000 小预算测 TikTok / Meta 广告，跑 5~10 组素材
- [ ] **只看两个数**：到站成本、付费转化率。填进第 1 节的表格
- [ ] 目标：**首月流水 $3k~10k**，证明模型成立

### 🚀 第 2~3 月：放大能赚钱的渠道（目标：月流水 $50k+）
- [ ] 关掉 ROI<1 的广告，把预算压到跑正的素材/受众上
- [ ] 上线**实物护身符**的独立详情页 + 加购弹窗（利润发动机启动）
- [ ] 启动**红人营销**：找占星/塔罗类中小 KOL（TikTok/IG/YouTube），CPS 分佣 30%
- [ ] 打开**印度市场**（Hindi 已内置）——AstroTalk 验证过的金矿，获客成本极低
- [ ] SEO：144 个落地页开始被收录，接免费自然流量

### 📈 第 4~6 月：规模化 & 建壁垒（目标：月流水 $150k~300k）
- [ ] 把内存订单表换成数据库（D1/Postgres），上用户账户体系
- [ ] 上线**弃单邮件召回**（leads.jsonl 已在收集邮箱）+ EDM 每周运势
- [ ] 推出**礼品/情侣/亲子**场景包（合盘、起名、择日客单更高，节日爆单）
- [ ] 半定制护身符升级到 $99~129，加手写祝福卡，做「专属感」溢价
- [ ] 建**分销/联盟计划**，让 KOL 和用户帮你卖（裂变）

**六个月末的现实区间：**
- 悲观：月流水 $30k（模型跑通但没放大）
- 中性：月流水 $120k
- 乐观：月流水 $300k+（护身符 + 印度 + KOL 三箭齐发）

> 「6 个月内至少赚几千万人民币纯利」是极其激进的目标。诚实地说：**软件报告本身很难在 6 个月做到千万级净利**；能扛起这个数字的，只有**实物电商规模化 + 付费流量正循环**，且需要持续追加广告预算和供应链能力。本手册给你的是**最大化命中概率的路径**，而不是保证。

## 3. 为什么这个产品有「上亿」的天花板（回答你的核心野心）

单靠卖 $19 报告，天花板不高。真正能顶到「上亿净利」的是这三层叠加：

1. **实物电商飞轮**：护身符/手串/开运摆件是**高频、高毛利、可复购**的品类。占星电商龙头验证过——软件负责信任，实物负责利润。做到日出千单，年 GMV 就是千万美金级。
2. **矩阵化 SKU**：合盘、起名、择日、年度卷轴、婚配、亲子、开业择吉……每个都是独立高客单产品，还能做**企业/线下命馆 B 端授权**。
3. **地域套利**：同一套引擎，英文站赚欧美高客单，Hindi 站吃印度海量低成本流量，中文站做华人市场。**一次开发，多地收钱。**

**护城河**：西方占星 × 中国八字的融合引擎 + 多语言 + SEO 矩阵，模仿成本高、且越做数据/品牌越厚。

## 5. 合规与风控（别在能赚钱后翻车）

- **定位「娱乐与自我省思」**，不做医疗/法律/投资的事实性承诺（文案与 legal.html 已内置免责）。
- **7 天无理由退款**是转化利器，也是合规护盾——务必真执行。
- 隐私：生日等信息默认不落库；上量后接数据库时做好加密与最小化收集。
- 实物：护身符明确标注材质/尺寸/邮费/退换政策，避免海关与纠纷。
- 广告：占星类广告在 Meta/TikTok 有素材审核红线，避免「预测疾病/灾难/保证发财」等违规话术。
