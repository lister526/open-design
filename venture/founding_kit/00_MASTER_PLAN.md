# 创业总纲 · Master Founding Plan
### 项目代号：**Wanka / 万卡** —— AI 原生「营销内容创作网络」
*(Working name; final brand TBD in §7. English handle candidate: **Everad / Adcraft / Sellframe**.)*

> 一句话定义（elevator pitch）：
> **"让每一个卖家、每一个小商家，都能在 3 分钟内用 AI 做出一整套会卖货的本地化图片、短视频和文案 —— 并且好作品会变成模板，被别人复用、被创作者变现，越用越强。"**
>
> One line (EN): *An AI-native creator network where any merchant turns a product into a full set of localized, conversion-ready images / short-videos / copy in minutes — and the best outputs become remixable templates that other merchants hire, so the network compounds.*

---

## 0. 为什么是这个（决策依据）
完整证据与门槛评分见 `../research/03_platform_archetype_decision.md`。压缩结论：

- 目标被明确为 **网络效应平台**（google/meta/uber/canva/airbnb 级），非代运营/服务公司。
- 消费级 AI 陪伴：留存差 + 监管雷（Character.ai 2025 崩），**否**。
- AI app-builder：被大模型吃、结局是被收购，**否**。
- Agent 交易市场：天花板最高，但三边冷启动，资源型独立创始人 2026 做不动 → **列为 24 个月后的扩张**。
- **Canva 级 AI 创作网络 → 收窄到「跨境/小商家营销内容」这个原子网络** = 唯一同时满足「$10B+ 天花板 / 文科无资源可冷启动 / 单机即有用不会冷启动死 / 中国+微信分发不对称优势 / 抗大模型替代（护城河是网络与结果数据不是模型）」的选择。**这就是这次的唯一下注。**

## 1. 使命 / 愿景 / 价值观
- **使命 Mission：** 消除"会做生意的人不会做内容"这个全球性结构痛点，让任何人 3 分钟做出能卖货的内容。
- **10 年愿景 Vision：** 成为全球中小商家的「营销内容操作系统 + 创作者经济网络」——商家在这里生产、复用、变现内容，广告平台在这里取素材，创作者在这里赚钱。
- **价值观：** ①结果导向（不是"好看"，是"卖得动"）②合规不骗客户 ③创作者优先（他们赚钱我们才赚钱）④越用越强（每个作品让下一个更好）。

## 2. 目标客户与原子网络（cold-start 的关键）
- **原子网络（第一个能自我维持的最小网络）：** 一个垂直的跨境/小商家人群 + 少量种子创作者。
  - 供给侧（硬的一边，先解决）：会做爆款内容的**种子创作者/达人**（20–100 人，创始人亲自 do-things-that-dont-scale 拉起来）。
  - 需求侧：**大量需要天天出内容的中小卖家**（自然增长 + 每个产出都是广告）。
- **首个垂直建议：** 3C/家居/美妆之一的跨境独立站 + TikTok Shop 卖家（痛点最尖、付费意愿已被验证：他们今天就在给 VA/代运营/剪辑付钱）。K1 用户访谈锁定。

## 3. 产品三层（单机有用 → 网络 → 市场）
1. **单机层（Day-1 价值）：** 上传产品/店铺 → AI 产出成套本地化素材（主图/详情图/短视频脚本+成片/多语言广告文案/卖点）。**无需任何其他用户即有用**，跨过冷启动死亡区。
2. **网络层（护城河形成）：** 好作品一键变「模板/配方（prompt+风格+结构）」→ 进入**模板/混剪图谱**，被别人 remix；创作者积累**粉丝 + 作品 + 收入**。
3. **市场层（take-rate + 复利）：** 模板/创作者**市场**（商家订阅或雇佣创作者、买模板）；平台抽成；沉淀**「哪个模板真的带来成交」的结果数据**——这是 GPT 复制不了的东西。

## 4. 护城河（为什么一年后的 GPT 吃不掉）
生成本身可被替代 → 护城河**不在生成**，在：
- (a) **可复用资产/模板网络**（越多越好用，Canva 同款飞轮，已验证[E]）；
- (b) **创作者身份+粉丝+收入**（他们没法把观众和收入搬去 ChatGPT → 高切换成本）；
- (c) **结果/转化数据**（哪些内容真的卖货 → 推荐更准 → 单机层更强 → 更多人来）；
- (d) **微信小程序 + 电商 + 短视频分发**（中国创始人独有、零 CAC）；
- (e) **支付/变现轨道**（marketplace 抽成 + 广告投放接口）。
四条数据/网络飞轮相互增强 → 网络效应，非模型效应。

## 5. 分发与增长（零/低 CAC，match "企业偏线上"）
- **内生病毒性：** 每个产出自带水印/署名 → 每条被发布的素材都是一次获客。
- **微信小程序：** ~410M–1B+ DAU，海外交易 2025 +40%[E] → 中国商家零摩擦入口 + 出海桥。
- **短视频/UGC：** 创作者把成片发到抖音/TikTok/小红书 → 反向拉新。
- **广告 SDK（AppLovin / Meta）：** ①平台自身变现；②商家做完素材**一键投放**（我们既造素材又接投放，闭环）。
- **不靠付费买量做主获客**（避开 paid-UA 陷阱，见短论 #11）。

## 6. 商业模式与定价（详见 `01_business_model.md`）
- 免费额度（credits）→ 订阅（月/年）→ 用量加油包 → 市场抽成（take-rate）→ 广告投放分成。
- 现金进项从第一天就有（订阅+加油包）→ 平台点燃前不至于饿死（survival design）。

## 8. 24 个月路线图（摘要，详见 `03_24_month_plan.md`）
- M0–1：K1 用户访谈（20+ 商家验证付费）→ 若通过再动代码。
- M1–3：单机层 MVP（web + 微信小程序），种子 200 模板，创始人亲拉 20–100 创作者。
- M3–6：iOS/Android + 病毒水印 + 订阅上线 → 验 D30 留存 & 模板复用（K3）。
- M6–12：模板/创作者市场 + 广告 SDK 投放闭环 → take-rate 起量。
- M12–24：多垂直复制 + 结果数据推荐 + 开始铺 Agent-outcome 市场（$100B 期权）。

## 9. Kill criteria（何时认输/转向，详见 research/03 §7）
- K1 2 周：<20 商家确认"今天就在为内容付费且愿试用" → 换垂直。
- K3 8–12 周：首批 D30 留存不达标 & 无人产出可复用模板 → 网络不成立 → 退回 B2B 服务兜底方案。
