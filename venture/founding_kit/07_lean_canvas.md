# 07 · 精益画布 (Lean Canvas) — 一页纸
项目：万卡 · AI 营销内容创作网络

| 区块 | 内容 |
|---|---|
| **① 问题 Problem** | 中小/跨境商家会做生意不会做内容；出内容慢/贵/不本地化；今天付钱给 VA/剪辑/代运营/通用工具但结果不带成交。 |
| **② 客户细分 Segments** | 早期采用者：TikTok Shop / 独立站 某品类跨境卖家 + 种子创作者。扩张：亚马逊/微信/抖音小商家 → 全球 SMB。 |
| **③ 独特价值主张 UVP** | "3 分钟，把一个产品变成一整套会卖货的本地化图/视频/文案；好作品变模板，别人复用、创作者变现——越用越强。" |
| **④ 解决方案 Solution** | 单机层(AI 成套素材) → 网络层(作品→模板/创作者) → 市场层(抽成+投放闭环+结果数据推荐)。 |
| **⑤ 渠道 Channels** | 病毒水印(每产出=广告)、微信小程序、创作者短视频外溢、卖家社群/KOC、SEO/GEO；付费买量仅增量。 |
| **⑥ 收入 Revenue** | R1 订阅 / R2 加油包 / R3 市场抽成 20% / R4 投放分成。 |
| **⑦ 成本 Cost** | AI 生成(API/GPU)、存储/CDN、支付通道、极小团队、（早期极低买量）。毛利目标 73%。 |
| **⑧ 关键指标 Metrics** | North-Star=每周"本平台生成并公开传播的内容数"；护栏=D30 留存/模板复用/创作者收入/付费转化/CAC/毛利。 |
| **⑨ 不公平优势 Unfair advantage** | 中国供给+微信零 CAC 分发(海外 +40%)[E]；先聚创作者+结果数据→网络效应；文科创始人分发/创作者关系强项 + AI 补产能。 |

**一句话下注：** 做**Canva×CapCut×创作者市场**的 AI 原生版，从跨境/小商家营销内容这个原子网络切入，用病毒+微信冷启动，以模板网络+创作者收入+结果数据+市场抽成筑网络护城河；$10B+ 为下限，Agent-outcome 市场为 $100B 期权。
