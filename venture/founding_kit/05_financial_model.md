# 05 · 财务模型（假设与收入反推）
项目：万卡。**全部为假设 [A]，用于反推所需漏斗，非承诺。** 需用 K1/K2/K3 实测校准。

## 1. 关键假设（初版）
| 变量 | 值 | 说明 |
|---|---|---|
| 付费 ARPU | ¥85/月 | Pro 为主、混合年付折算 |
| 毛利率 | 73% | 见 01_business_model §3 |
| Free→Paid 转化 | 5% | 需实测（消费级偏低、工具/结果导向可更高）|
| 月流失 (churn) | 6%→4% | 靠创作者收入/粉丝/工作流锁定压降 |
| 病毒系数目标 | K>0.4 | 每产出带水印；非纯病毒但显著降 CAC |
| Blended CAC | <¥30 | 病毒+微信+UGC 为主 |

## 2. 收入反推（年订阅收入 = 付费用户 × ¥85 × 12）
| 目标年订阅收入 | 所需付费用户 | 若转化5%所需注册用户 | 备注 |
|---|---|---|---|
| **¥5000 万** | ≈ 4.9 万 | ≈ 98 万 | P3 中后期可达（单垂直+病毒）|
| **¥1 亿** | ≈ 9.8 万 | ≈ 196 万 | P3→P4，需 2–3 垂直 |
| **¥3 亿** | ≈ 29.4 万 | ≈ 588 万 | P4 多垂直 + 市场抽成叠加 |
*(以上仅订阅 R1；叠加 R2 加油包 +20–40%、R3 市场抽成、R4 投放分成后，同等用户可显著抬高总收入。)*

## 3. 三年情景（示意，¥）
| | Y1(保守) | Y2(基准) | Y3(乐观) |
|---|---|---|---|
| 注册用户(累计) | 20 万 | 150 万 | 700 万 |
| 付费用户 | 6 千 | 6 万 | 35 万 |
| 年订阅收入 | ¥600 万 | ¥6120 万 | ¥3.57 亿 |
| +加油包/市场/投放 | +30% | +50% | +80% |
| **总收入(约)** | ¥780 万 | ¥9200 万 | ¥6.4 亿 |
| 毛利(73%) | ¥570 万 | ¥6700 万 | ¥4.7 亿 |
| 团队规模 | 2–5 | 8–15 | 25–50 |

## 4. 估值锚（对标，非承诺）
- Canva ~$42B / ~2.3 亿用户（模板+分享飞轮）[E]。
- 若 Y3 达 ¥6 亿收入 + 网络效应验证 + 高增速 → 具备冲击 US$1–3B 估值的结构；十亿→百亿美元需 R3/R4 网络复利在后续年份兑现（期权）。

## 5. 现金安全线
- Y1 靠 R1+R2 覆盖 AI 成本 + 极小团队，尽量不烧钱到断粮。
- 融资只在 K3 通过（网络在形成的证据）之后，以数据换估值。

## 6. 必须实测校准的 5 个数（否则模型是空中楼阁）
1. 真实 Free→Paid 转化。 2. 真实月流失。 3. 真实每用户 AI 成本。 4. 病毒系数 K。 5. 模板复用率 & 创作者留存。
