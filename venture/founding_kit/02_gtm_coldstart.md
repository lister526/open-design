# 02 · GTM 与冷启动 · 增长飞轮
项目：万卡。理论依据：Andrew Chen《The Cold Start Problem》[E] + Airbnb/Canva 早期打法[E]（见 research/03 §1.3–1.4）。

## 1. 核心原则（来自证据，不是拍脑袋）
1. **不要一上来做市场（marketplace）**——先做单机有用的工具，凑够"现成供给"再变网络。
2. **先解决硬的一边**（供给=会做爆款的种子创作者），需求侧自然被拉动。
3. **Do things that don't scale**：创始人亲自服务前 100 个用户，不到第 1 个用户"爱上"绝不去第 2 个（Airbnb/Chesky 原则）。
4. **原子网络**：锁定一个垂直（如 TikTok Shop 家居卖家），在这一个小网络里跑通，再复制。

## 2. 冷启动三步（0 → 网络）
### Step A（M0–1）：需求证伪（无代码）——对应 K1
- 找 20+ 目标商家（微信群/知乎/卖家社群/1688/TikTok Shop 卖家群）做访谈：
  - 今天怎么出内容？付了多少钱给谁（VA/剪辑/代运营/工具）？最痛的是什么？愿不愿试/付？
- 通过标准：≥20 人确认"现在就在为内容付费 + 愿意试用"。**不过则换垂直，不写产品代码。**

### Step B（M1–3）：单机层 MVP + 种子供给
- 造 **200 个高质量模板**（创始人+外包 AI 内容，先把"现成供给"堆出来）。
- 亲拉 **20–100 个种子创作者/达人**（give them free Pro + 曝光 + 早期分成），让他们把作品变模板。
- 目标：让第一批商家"用一次就离不开"（单机价值）。

### Step C（M3–6）：网络翻转 + 病毒
- 上线"作品→模板"一键化 + 创作者主页/粉丝/收入。
- 每个免费产出带水印署名 → 病毒获客；创作者把成片发抖音/TikTok/小红书 → 反向拉新。
- 微信小程序上线 → 零摩擦分享裂变。

## 3. 增长飞轮（网络效应闭环）
```
商家来 → 用 AI 出内容(单机价值) → 好内容变模板/创作者变红
   ↑                                          ↓
更多商家被吸引 ← 模板越多越好用 + 成片到处传(病毒) ← 创作者赚钱留下
   ↑                                          ↓
结果数据(哪些内容真卖货) → 推荐更准 → 单机层更强 —————┘
```
四个环：**UGC 资产环、创作者收入环、病毒分发环、结果数据环**——彼此增强。

## 4. 渠道优先级（低/零 CAC 先行）
1. 内生病毒水印（每条产出=广告）——0 CAC。
2. 微信小程序 + 社群裂变——0 CAC，中国独有。
3. 种子创作者的短视频外溢（抖音/TikTok/小红书）——0 CAC。
4. 卖家社区/KOC 合作、内容 SEO/GEO——低 CAC。
5. AppLovin/Meta 付费买量——**只做增量放大，不做主获客**（避 paid-UA 陷阱）。

## 5. 从"一个原子网络"到"全球平台"的扩张次序
垂直 1（TikTok Shop 某品类卖家）→ 相邻品类 → 独立站/亚马逊卖家 → 中国本地小商家(微信/抖音) → 全球 SMB → （M12+）Agent-outcome 市场扩张（$100B 期权）。
每次复制沿用同一飞轮，模板/结果数据跨垂直复用 → 复利。

## 6. 关键指标（North-Star & 护栏）
- North-Star：**每周发布的"由本平台生成并公开传播"的内容数**（同时衡量价值+病毒）。
- 护栏：D30 留存、模板复用率、创作者月收入、付费转化、blended CAC、毛利率。
- K3 门槛：首批 D30 留存达标 且 有人产出可复用模板 → 网络在形成；否则 kill。
