# SpacePilot — One-Pager (一页纸融资/招客介绍)

**AI Listing Revenue Upgrade OS for short-term rentals**
让短租房东知道"为什么少赚钱"，并一键买到能补上收益缺口的升级方案。

---

## The Problem (问题)
全球有数千万 Airbnb / Vrbo / 服务式公寓房源，**大多数房东不知道自己每月漏掉了多少钱**：
- 定价错、照片弱、缺少高转化设施（快 WiFi、工作角、遮光、家庭友好装备）。
- 房东想升级，但**不知道升什么、值不值、找谁做**。
- 结果：低入住率、低夜间价、差评、被平台降权——收益长期低于潜力 15%–40%。

## The Solution (方案)
SpacePilot 是一条**"诊断→方案→执行→复盘"**的收益提升流水线：
1. **免费漏损扫描 (Leak Scan)** — 输入房源信息，给出收益漏损分数 + 每月潜在增收区间。
2. **$149 深度审计 (Audit)** — 生成《房源表现护照》：定价、设施、合规、竞品对标。
3. **$799–$1,299 升级提案 (Proposal)** — 可购买的升级套件 + 明确报价 + 回本周期。
4. **本地交付协调 (Delivery)** — 对接本地供应商，SpacePilot 收 **10%–15% 协调费**。
5. **照片级交接 + 前后收益追踪** — 证明 ROI，形成复购与口碑。

## Why Now (为什么是现在)
- 短租监管趋严 + 平台算法更看重"体验信号" → 房东被迫升级。
- 生成式 AI 让"个性化诊断 + 报价"第一次可以低成本规模化。
- 装修/设施供应链在很多城市碎片化，缺一个可信的协调层。
