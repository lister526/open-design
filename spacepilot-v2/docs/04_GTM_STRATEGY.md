# SpacePilot — Go-To-Market Strategy (进入市场策略)

> 你钱不多，所以 GTM 的核心原则只有一个：**用时间和内容换客户，先手工、后自动。**

---

## 1. Beachhead：先只打一个城市 + 一类房东
- **一个城市**：你最有资源/人脉/能跑腿的城市（能对接本地供应商）。
- **一类房东**：自管、1–5 套、有痛感（入住率或价格低于同区）。
- 理由：本地交付需要供应商网络；一城做透再复制，别一开始全球撒网。

## 2. 冷启动获客（$0 预算优先）
按"投入产出比"排序：

1. **公开漏损拆解（最强）**
   - 找 3–5 个真实公开房源，用 SpacePilot 做"收益漏损诊断"，写成图文/短视频。
   - 发到：小红书、Reddit r/AirBnB、Facebook 短租群、抖音/B站、LinkedIn。
   - CTA：「想免费诊断你的房源？私信/填表」。案例本身就是广告。

2. **社群手动获客**
   - 加入 10–20 个短租房东社群，先真诚回答问题、给价值，再自然引流。
   - 目标：拿到 **20 个愿意被免费诊断的房东**。

3. **供应商互导**
   - 找本地清洁工、摄影师、智能锁/家具商，谈"我给你带活儿，你给我推房东"。

4. **SEO（慢但复利）**
   - 写「如何提高 Airbnb 入住率 / 定价 / 照片」等长尾文章，埋诊断入口。

## 3. 转化路径（漏斗话术）
```
免费漏损扫描  →  "你每月大约漏了 $X"
      ↓ 制造缺口感
$149 深度审计  →  "花$149看清具体怎么补，并给你回本方案"
      ↓ 用回本周期说服
$799–1,299 提案 → "这套升级预计 N 个月回本"
      ↓
本地交付 + 追踪 → "做完我帮你盯，前后收益对比"
```
每一步都要有**明确的下一步 CTA** 和**风险逆转**（如：审计不满意退款）。

## 4. 定价与风险逆转
- 审计 $149，主打**低门槛试水** + "不满意全额退"（降低第一次付费恐惧）。
- 提案报价必须带**回本周期**（客户买的是 ROI，不是装修）。
- 早期可给"前 5 名种子客户"折扣，换取**案例 + 证言**。

## 5. 早期"人肉 MVP"（concierge）
- 不要等自动化。**你手动**完成：诊断→写报告→找供应商→协调→交接。
- 目的：先证明客户愿付 + 交付能成，再把重复动作产品化。

## 6. GTM 里程碑
| 阶段 | 目标 |
|---|---|
| 第 1 周 | 发出 3 个公开诊断案例；进 10 个社群 |
| 第 2–3 周 | 收集 20 个免费诊断需求；≥3 人付 $149 |
| 第 4–8 周 | 跑通 1 单完整交付；做成公开案例 |
| 第 9–12 周 | 复制到 3–5 单；招 3–5 家供应商 |

## 7. 需要准备的物料
- 落地页（已有：本项目静态站点，先部署上线）。
- 收款方式（Stripe Payment Link / 微信/支付宝收款码 — 手动即可）。
- 一份诊断报告模板（可先用文档手写，别急着做后端）。
- 3 条"公开诊断"内容脚本。
