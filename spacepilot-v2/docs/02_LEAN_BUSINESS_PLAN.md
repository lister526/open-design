# SpacePilot — Lean Business Plan (精益商业计划)

> 用精益画布 (Lean Canvas) 结构写，目的不是"完美计划"，而是**列清最危险的假设并逐个验证**。

---

## 1. Customer Segments (客户细分)
**早期采用者（先打这群人）：**
- 拥有 1–5 套短租房、**自己管理**、把它当收入来源的房东（非酒店集团）。
- 房源已上线 6 个月以上、入住率或价格明显低于同区（"有痛感、能对标"）。
- 城市从 **1 个试点城市**开始（供应商可控），例如你所在城市 / 有资源的城市。

**次级：** 小型民宿管家 / 房产管理公司（可批量带房源）。

## 2. Problem (问题 · 前三大)
1. 不知道自己的房源**为什么比别人少赚**（信息不对称）。
2. 想升级但**决策困难**：升什么、花多少、值不值。
3. **找不到可信的本地执行方**，怕被坑、怕麻烦。

**现有替代方案：** 自己瞎摸索 / 看 YouTube / 找装修队 / 用通用动态定价工具（只解决定价一环）。

## 3. Unique Value Proposition (独特价值主张)
> "10 分钟看清你的房源每月漏了多少钱，并给你一套可直接下单、能算清回本的升级方案。"
把**诊断—报价—执行—复盘**做成一条闭环，而不是只卖一个工具。

## 4. Solution (对应三大问题)
1. AI 漏损扫描 + 表现护照 → 解决"不知道为什么"。
2. 场景化提案 + 明确报价 + 回本周期 → 解决"决策难"。
3. 本地供应商协调 + 交接验收 → 解决"找不到可信执行方"。

## 5. Channels (渠道)
- **冷启动**：短租房东社群（微信群、Facebook Groups、Reddit r/AirBnB、小红书）。
- **内容**：拿真实房源做"漏损诊断"公开拆解（案例即广告）。
- **合作**：清洁公司 / 摄影师 / 智能锁经销商互相导流。
- 后期：SEO（"how to increase airbnb bookings"）+ 平台合作。

## 6. Revenue Streams (收入)
- 审计 $149（数字产品，毛利极高）。
- 提案 $799–$1,299（含方案设计 + 首轮协调）。
- 交付协调费 施工款的 10%–15%。
- （未来）订阅：持续追踪 + 季度再优化。

## 7. Cost Structure (成本)
- 早期几乎为零：域名 + 静态托管（免费）+ 你的时间。
- 变动成本：AI API 调用（真上线后）、支付手续费、少量获客投放。
- 关键：**先靠人力手工交付**（concierge MVP），别急着写复杂后端。

## 8. Key Metrics (关键指标)
- 漏斗：扫描数 → 审计付费率 → 提案转化率 → 交付率。
- 北极星：**已完成交付并被追踪到收益提升的房源数**。
- 现金：每单毛利、回款周期。

## 9. Unfair Advantage (壁垒 · 诚实)
- 现在**没有**真正壁垒。可积累的壁垒：
  - 城市级供应商网络 + 交付质量数据。
  - 房源前后收益的真实数据集（越用越准的漏损模型）。
  - 房东信任 + 案例口碑。

## 90 天目标（务实）
- 第 1–30 天：验证愿付（≥3 人付 $149）。见 `05_VALIDATION_PLAN.md`。
- 第 31–60 天：跑通 1 单完整交付（找 1 家供应商手工协调）。
- 第 61–90 天：把这单做成公开案例，复制到 3–5 单。
