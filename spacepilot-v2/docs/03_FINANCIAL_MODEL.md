# SpacePilot — Financial Model & Unit Economics (财务模型与单位经济)

> 所有数字都是**假设**，用来算清"要赚到目标利润需要多少客户"。
> 你必须用真实验证数据替换它们。别把假设当事实。

---

## 1. 单位经济 (Per-Customer Unit Economics)

### 一个"完整客户"的收入构成
| 项目 | 金额 (USD) | 说明 |
|---|---|---|
| 审计 Audit | $149 | 数字产品 |
| 提案 Proposal | $999 | 取 $799–$1,299 中值 |
| 交付协调费 | $600 | 假设施工款 $5,000 × 12% |
| **单客总收入** | **≈ $1,748** | 完整走完闭环 |

### 单客成本（早期 concierge 手工模式）
| 项目 | 金额 (USD) | 说明 |
|---|---|---|
| AI / 工具 | $5 | API 调用 |
| 支付手续费 | ~$52 | ≈3% |
| 你的人工时间 | (不计现金) | 早期用时间换 |
| 获客成本 CAC | $50–$150 | 早期靠内容/社群可更低 |
| **单客现金成本** | **≈ $110–$210** | |

### 单客毛利
> ≈ $1,748 − $180 ≈ **$1,568 / 完整客户**（不含你的人工）

**关键洞察：** 只有约 **10% 的扫描用户**会走到完整交付。所以真正决定收入的是**漏斗转化**，不是单价。

## 2. 漏斗假设 (Funnel — 保守 / 中性 / 乐观)

| 环节 | 保守 | 中性 | 乐观 |
|---|---|---|---|
| 免费扫描 → 付费审计 | 3% | 6% | 10% |
| 审计 → 提案 | 25% | 40% | 55% |
| 提案 → 成交交付 | 30% | 45% | 60% |
| **扫描 → 完整客户** | **0.23%** | **1.08%** | **3.3%** |

> 读法：中性情况下，**每 100 个免费扫描 ≈ 1 个完整客户**。

---

## 3. 收入推演 (Revenue Projection — 中性假设)

设：中性漏斗，完整客户收入 $1,748，审计单独收入 $149。

| 月扫描量 | 付费审计 (6%) | 完整客户 (~1%) | 月收入估算* |
|---|---|---|---|
| 200 | 12 | 2 | ≈ $4,700 |
| 1,000 | 60 | 11 | ≈ $23,500 |
| 5,000 | 300 | 54 | ≈ $117,000 |

\* 月收入 = 完整客户×$1,748 + 仅审计客户×$149。粗算，仅示意量级。

**要点：** 收入 ∝ 流量 × 转化。前期你缺的不是定价，是**可信流量**和**证明能交付**。

## 4. 达到不同利润目标需要什么规模

假设月运营固定成本 $2,000（工具+外包+少量投放），毛利率按上面算。

| 目标 | 需要的月扫描量（中性） | 现实难度 |
|---|---|---|
| 覆盖成本（~$2k/月） | ~150–200 | 数周内可能 |
| $10k/月净利 | ~600–800 | 3–6 个月，需稳定获客 |
| $50k/月净利 | ~3,000–4,000 | 12+ 个月，需团队+多城市 |
| "年入千万净资产" | 见下 | 见 `07_FOUNDER_REALITY_CHECK.md` |

## 5. 关于"一年数千万净资产"的数学
- 数千万净资产（假设 ¥3,000 万 ≈ $4M+）在一年内实现，需要：
  - 要么公司年化收入达数千万且有高倍数估值退出；
  - 要么单点爆发式增长 + 融资估值。
- 以本模式（服务+协调费为主、毛利健康但**非病毒式**），**一年达成的概率极低**。
- 更现实的路径：**先在 6–12 个月做到月净利 $5k–$20k 并跑通可复制交付**，再谈规模化/融资。

> 不是打击你，是让你把有限的钱花在**能验证的下一步**，而不是过早铺大摊子。详见 `07`。

## 6. 你现在应该盯的 3 个数字
1. **有没有人付第一笔 $149**（愿付验证）。
2. **一单交付能不能真的做出来、客户满不满意**（交付验证）。
3. **一个付费客户的真实获客成本**（渠道验证）。
这三个数字为真，模型才有意义；否则上面所有数字都是空中楼阁。
